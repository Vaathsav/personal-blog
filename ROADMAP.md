# Personal Blog Roadmap

## Vision

Build a fast, simple, and readable personal website focused on software engineering.

The website should feel like an engineer's notebook where I share practical knowledge, projects, and lessons learned while building software.

The goal is to create something that software engineers enjoy reading and hiring managers respect.

---

# Design Principles

## Fast Loading

- Static-first architecture
- Minimal JavaScript
- Optimized assets
- Excellent Lighthouse score

---

## Simplicity

- Every page has one purpose.
- No unnecessary animations.
- No visual clutter.
- Navigation should be obvious.

---

## Readability

- Content is the focus.
- Comfortable typography.
- Consistent spacing.
- Good contrast.
- Minimal distractions.

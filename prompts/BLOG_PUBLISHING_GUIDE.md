# Blog Publishing Guide

## Purpose

This guide defines how articles are prepared and published on the personal blog.

## Article Preparation

When converting an existing article into the blog format:

- Preserve the author's original meaning and voice.
- Do not invent facts, examples, opinions, or experiences.
- Do not unnecessarily rewrite the article.
- Preserve the author's structure where possible.
- Use valid Markdown formatting.
- Format code using fenced code blocks and specify the language when known.
- Keep technical terminology unchanged.

## Frontmatter

Every blog post must contain:

- `title`
- `description`
- `publishDate`
- `tags`
- `draft`

New articles should use:

draft: true
